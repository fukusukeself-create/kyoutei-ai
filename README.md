# 競艇AI予想 (kyoutei-ai)

ボートレースの情報を自動で集めて、AIが3連単の買い目を**フォーメーション**で出すアプリです（Streamlit）。

## 使い方

1. **開催一覧** または **締切順** からレースを選ぶ
2. 予想画面が開き、すぐに「データ予想（統計AI）」の買い目が出る
3. **「AIに展開を読んでもらい、最終の買い目を出す」** を押すと、AI（Claude Opus 5.5）が進入・スタート・機力・風から展開を読んで最終の買い目を出す
4. 展示（直前情報）は締切の15〜30分前に出る。レースを開いたままにしておけば、締切45分前から30秒ごとに
   自動で確認し、出た瞬間に展示タイム・スタート展示（進入・ST）・風を反映した予想に切り替わる
   （手動で取り直したい時は **「最新の展示・オッズに更新」**）

買い目は「1着 ▶ 2着 ▶ 3着」の箱に艇番（公式の枠色）を並べて表示します。画面の
「フォーメーションの読み方・買い方」に、テレボートでの買い方の手順も書いてあります。

買い方は3種類から選べます（既定は **バランス**）。

| 買い方 | 点数の上限 | 過去データでの的中の目安 |
|---|---|---|
| 的中重視 | 20点 | 約7割 |
| バランス | 12点 | 約5〜6割 |
| 少点数 | 6点 | 約4割 |

**トリガミ回避**（既定でオン）: オッズを見て、どの買い目が当たっても購入額を上回るところまで点数を自動で絞ります。
バランスだと平均7点ほどになり、的中は約4割に下がりますが、「当たったのにマイナス」が無くなります。

※ 的中の目安は過去レースでの検証値で、将来の的中を保証するものではありません。

## 収支についての検証

「収支プラスになる買い方」を過去データで探しましたが、**回収率が100%を超える方法は見つかっていません**。
舟券は売上の25%が先に引かれるため、何も工夫しないと回収率は約75%になります。検証で分かったことは次のとおりです。

検証の条件: モデルは検証期間より前のデータだけで学習（学習外）。1点100円の均等買い。

**学習外60日・8,960レース（オッズを使わない買い方）**

| 買い方 | 回収率 |
|---|---|
| いまの3種類（的中重視／バランス／少点数） | どれも約75% |
| 確率の高い順に上位1点だけ | 約82% |
| 上位12点 | 約76% |
| 本命の買い目の確率が12%以上のレースで、上位1点だけ | 約88% |
| 確率1%未満の買い目（穴）を全部 | 約58% |
| 単勝・複勝で確率の高い艇だけ | 約91〜94% |

**確定オッズつき10日・1,380レース（オッズを使う買い方）**

| 買い方 | 的中 | 回収率 | 当たってもマイナス | 1レースの損益 |
|---|---|---|---|---|
| バランス（オッズを使わない） | 54.9% | 76.5% | 43% | −279円 |
| バランス＋オッズを確率に取り込む | 56.5% | 76.9% | 42% | −273円 |
| **バランス＋オッズ取り込み＋トリガミ回避（いまの既定）** | 42.9% | 80.4% | 0% | −142円 |
| 予測では割安に見える買い目だけ（期待値1.15以上） | – | 67.5% | – | – |

- 的中組合せの予測は、**オッズ（世間の評価）のほうがこのアプリのモデルより正確**でした。予測とオッズが食い違う時に
  予測を信じて買うと、回収率はむしろ下がります（67.5%。10日のうち8日がマイナス）。
- 穴ほど回収率が低く、確率の高い買い目ほど高い。点数を増やすほど回収率は下がります。
- 損を小さくするのに効いたのは、**点数を絞ること**と**当たった時に購入額を割らないこと**でした。

このため、アプリは「展示後はオッズを確率に半分取り込む」「トリガミが出ない点数まで絞る」を既定にしています。
それでも長く買い続ければ、平均して購入額の約2割が減っていく計算です。

## 集めている情報

| データ元 | 取っている情報 |
|---|---|
| [ボートレース公式サイト](https://www.boatrace.jp/) | 開催一覧、出走表（勝率・モーター・今節成績）、直前情報（展示タイム・スタート展示・チルト・部品交換・気象）、3連単オッズ、当日の結果と決まり手、場のコース別成績 |
| [BOATCAST](https://race.boatcast.jp/) | オリジナル展示（一周・まわり足・直線） |
| [Boatrace Open API](https://boatraceopenapi.github.io/) | 過去レース（モデル学習用）。公式サイトに繋がらない・遅い時の予備 |

**ボートレース日和（kyoteibiyori.com）について**: 利用規約（第5条）で、プログラムによる自動取得と
AI解析への利用が禁止されているため、このアプリからは取得していません。
予想画面の下に、そのレースの日和のページを開くリンクを置いてあります。
日和で見て気づいたことは「AIに伝えたいメモ」欄に書くと、AIが予想に反映します。

## 予想のしくみ

1. **データ予想モデル（統計AI）** … `kyotei/model.py`
   過去約1年・約6万レースの出走表／展示／結果から学習。コース、場ごとのイン有利度、勝率、級別、
   モーター、平均ST、今節成績、選手のコース別成績、展示タイム、展示ST、進入、風（追い風／向かい風）、
   波などから、3連単120通りの確率を計算します。
2. **買い目の作成** … `kyotei/formation.py`
   決めた点数以内で「当たる確率の合計」が最大になるフォーメーション（本線＋抑え）を探します。
3. **AI（Claude Opus 5.5）による最終予想** … `kyotei/ai.py`
   集めた資料・モデルの確率・買い目ごとのオッズ・上の検証結果を渡し、展開予想・各艇の評価・最終の買い目と、
   そのレースを買う価値（勝負／通常／見送り）を出してもらいます。

## セットアップ

```bash
pip install -r requirements.txt
streamlit run app.py
```

AIの最終予想には Anthropic の APIキーが必要です。

1. [Claude Console](https://platform.claude.com/) にログインし、**API Keys → Create Key** でキーを作る（`sk-ant-` で始まる文字列。作成時に一度しか表示されません）
2. Streamlit Community Cloud のアプリの **Settings → Secrets** に次の1行を登録する（手元で動かす時は環境変数でも可）

```toml
ANTHROPIC_API_KEY = "sk-ant-ここにキー"
```

- 使うモデルは `claude-opus-5-5`（環境変数 `CLAUDE_MODEL` で変更可）。考える深さは `CLAUDE_EFFORT`（既定 `high`）。
- 料金は使った分だけ Console のクレジットから引かれます。1回の予想で 入力約4千・出力数千トークン、
  およそ0.1ドル前後が目安で、実際の利用量は予想のたびに画面下（「AIに渡した資料」の下）に表示されます。
- `ANTHROPIC_API_KEY` が無く `GEMINI_API_KEY` だけ登録されている時は、これまでどおり Gemini（既定 `gemini-3.6-flash`、
  `GEMINI_MODEL` で変更可）で予想します。
- APIキーが1つも無くても、データ予想（統計AI）の買い目は使えます。

URLに `?hd=20261125&jcd=5&rno=1` を付けると、日付・場・レースを直接開けます。

公式サイトは1ページの応答に10秒ほどかかることがあるため、1レースぶんのページ（出走表・直前情報・
オッズ・結果・場データ）は同時に取りに行き、最大20秒待ちます（環境変数 `KYOTEI_OFFICIAL_TIMEOUT` で変更可）。
それでも取れない時は3分間だけ予備データ（Boatrace Open API）に切り替えます。ただし予備データは
直前情報の反映が遅いので、展示を使った予想には公式サイトに繋がることが必要です。

## モデルの学習し直し

選手の成績は少しずつ変わるので、1〜2か月に一度の学習し直しをおすすめします。

```bash
pip install scipy
python scripts/train_model.py --days 365
```

`kyotei/model_weights.json`（モデルの重み）と `kyotei/racer_stats.json`（選手のコース別成績）が
更新されるので、コミットしてください。

## テスト

```bash
pip install pytest
python -m pytest tests
```

## 注意

予想は的中を保証するものではありません。舟券の購入は20歳以上、無理のない金額で。
