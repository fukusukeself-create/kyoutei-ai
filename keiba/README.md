# 🏇 中央競馬 AI予想

JRA (中央競馬) の開催一覧からレースを選ぶと、馬柱の統計レーティングと Gemini の見解を
合わせて勝率を出し、単勝・馬連・ワイド・三連複の買い目を組む Streamlit アプリ。
スマホ幅 (380〜450px) に最適化。予想は台帳に残して結果と答え合わせできる。

## 画面

1. **開催一覧** — 日付を選ぶと開催場ごとにレース一覧 (発走時刻・コース・頭数・格)。
   開催が無い日は次の開催日を案内。今日ならこれから発走するレースを強調。
2. **予想** — 出馬表・近5走・オッズを取得し、「予想する」で
   - 印 (◎○▲△☆) と推定勝率・3着内率・単勝オッズ・期待値・根拠
   - AI の見解 (ペース・展開・勝負のポイント・危険な人気馬・馬別コメント) ※AI併用時
   - 買い目: 単勝 (期待値1.1倍以上のみ) / 馬連 / ワイド / 三連複。スタイルは
     堅実 (点数を絞る) / バランス / 穴狙い (馬連15倍以上・三連複50倍以上の期待値順)
   - 発走前ならオッズを更新して組み直せる。確定後は結果と払戻も表示
3. **成績** — 台帳に保存した予想を結果と突き合わせ、的中率・回収率・収支を券種別に集計。CSV書き出し可。

## 予想の仕組み

| 段階 | 内容 |
|---|---|
| レーティング (`model.py`) | 近5走の着順・着差・クラス差・同条件か (芝ダ/距離)、人気と着順のズレ、休み明け、騎手、斤量差、馬体重の急変、多頭数外枠、脚質構成による展開 (単騎逃げ/先行過多) を点数化し softmax で勝率に |
| 市場との混合 | 単勝オッズから控除率を除いた市場確率と幾何平均 (市場 0.6 : モデル 0.4)。オッズ未発売ならモデルのみ |
| AI (`predictor.py`) | Gemini に出馬表・馬柱・馬場・モデル勝率を JSON で渡し、馬別 1〜5 評価と展開の見解を JSON で受ける。評価で勝率を上下 (5:×1.4 … 1:×0.6)。**オッズは渡さない** (渡すと人気に引きずられ、市場との差という妙味の根拠が消える) |
| 買い目 (`strategy.py`) | 勝率から Harville 式 (2・3着は指数で緩和) で馬連・ワイド・三連複・3着内の確率を作り、確率の高い順に目標の的中率に届くまで買う。オッズがあれば期待値を併記し、1.0 超は緑で強調 |
| 台帳 (`ledger.py`) | SQLite に予想を保存し、netkeiba の払戻で 1点100円換算の回収率を集計 |

## データ

netkeiba (race.netkeiba.com) の会員登録なしで見られるページのみ。JRA公式サイトはクラウドからのアクセスを拒否するため使っていない。

- 開催カレンダー・レース一覧・出馬表・近5走馬柱・単複/馬連/ワイド/三連複オッズ・結果と払戻

## 動かす

```bash
cd keiba
pip install -r requirements.txt
export GEMINI_API_KEY=...     # 省略可。無ければ統計モデルのみで予想する
streamlit run app.py
```

環境変数:

| 変数 | 既定 | 用途 |
|---|---|---|
| `GEMINI_API_KEY` | (なし) | Google AI Studio の API キー。Streamlit Cloud なら Secrets に同名で入れてもよい |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 使うモデル。混雑・利用枠超過時は `gemini-3.5-flash` → `gemini-2.5-flash` に自動で切り替える |
| `DATA_DIR` | `keiba/data` | 台帳 (SQLite) の保存先。Streamlit Cloud / Render 無料プランでは再デプロイで消えるので CSV で控えること |

Streamlit Community Cloud にデプロイする場合は Main file path に `keiba/app.py` を指定する。

## 注意

- 馬券の控除率は 20〜27.5% あり、どの買い方でも長期的な利益は保証されない。期待値 1.0 超の買い目だけが理論上のプラス。
- レーティングは公開情報を人手のルールで点数化したもので、過去データで学習・検証したモデルではない。台帳で答え合わせを続け、当たらない券種は買わないこと。
- 予想は参考情報であり、購入は自己責任で。20歳未満の馬券購入は法律で禁止されている。
