# 🏇 中央競馬 統計予想

JRA (中央競馬) の開催一覧からレースを選ぶと、**過去レースから学習した統計モデル**が
各馬の勝率を出し、単勝・馬連・ワイド・三連複の買い目を組む Streamlit アプリ。
AI (LLM) は使わない。競艇日和アプリと同じ操作感 (開催一覧 → 場・R → ⚡予想) で、
スマホ幅 (380〜450px) に最適化。予想は台帳に残して結果と答え合わせできる。

## 画面の流れ

1. **開催日** を選ぶ (既定は今日。開催が無い日は次の開催日を案内)
2. **🏁 開催一覧** の場カードをタップ → その場の次のレースをそのまま予想。
   **⏰ 発走順** タブなら全場のレースを発走時刻順に選べる
3. 別のレースは **開催場 / レース** のピルで選び **⚡ 予想する**
4. 出るもの
   - 判定バナー: 本命・勝率・自信 (自信あり / 普通 / 混戦)。枠順確定前は仮番号である旨も
   - **単勝 (基本)** — 期待値 (勝率 × オッズ) が検証で決めた下限以上の馬を買う (勝負)。いなければ見送らず、
     期待値が最も高い馬を1点。オッズ発売前は勝率1位を仮に出し、「オッズ更新」で選び直す
   - **三連複 (カチカチに固いレースだけ)** — 本命が圧倒的 (モデルの勝率 50% 以上) で、かつ上位3頭の勝率合計が 85% 以上
     (全体の約4%、1日1レースほど) のときだけ、確率の高い順に2点をフォーメーション表記で出す
   - 印・推定勝率・3着内率・単勝オッズ・期待値・**調教評価 (A〜Dと短評)・騎手の直近60日・父系統・母父系統**・根拠
   - 出馬表・近5走・血統 (父・母父)・調教
   - 発走前は「オッズ更新」で組み直し。確定後は結果と払戻
5. **📒 成績・答え合わせ** — 台帳の予想を払戻と突き合わせ、券種別の的中率・回収率・収支。CSV書き出し可
6. **📈 モデルの検証成績** — 学習に使っていない直近期間での成績 (市場との比較)

## 予想の仕組み (統計モデル)

| 段階 | 内容 |
|---|---|
| データ (`backtest/collect.py`) | netkeiba から 2023年以降の全レースについて、**出走時点の馬柱** (近5走・父・母父・脚質・間隔・馬体重) と **結果・払戻・確定オッズ** を収集し SQLite に保存 |
| 特徴量 (`features.py`) | 近5走の着順・着差・人気・クラス差・上り、**同じ芝ダ / 距離帯 / 競馬場 / 馬場状態での成績 (距離適性・コース適性)**、昇級か降級か、休み明け、斤量と平均との差、馬体重と増減、枠・馬番、年齢・性別、脚質と展開 (逃げ先行の頭数)、**父の芝ダ×距離帯別成績・母父の芝ダ別成績 (血統)**、騎手・厩舎の勝率と3着内率 (いずれも学習期間から平滑化して算出) |
| 学習 (`backtest/train.py`) | LightGBM の二値分類 (勝ち / 3着内) を学習し、レース内で正規化して勝率に。学習期間と検証期間を時系列で分け、検証期間で市場 (単勝オッズ) と対数損失・1番手的中率・回収率を比較 |
| 確率 (`statmodel.py`) | オッズが出ていれば **市場+統計補正モデル** (単勝オッズの確率のロジットを初期値にし、木は統計特徴量で市場からの補正分だけを学ぶ)。未発売なら統計のみのモデル。期待値 = 勝率 × 実オッズ |
| 買い目 (`strategy.py`) | 勝率から Harville 式 (2・3着は指数で緩和) で馬連・馬単・ワイド・三連複・三連単の確率を作る。収支プラス狙いは期待値 (確率×実オッズ) が下限を超える組、フォーメーションは確率順に目標の的中率に届くまで |
| 賭け方の検証 (`backtest/profit.py`) | 学習外の予想で、券種ごとの期待値の下限 (1.0〜1.5) を 2025年で選び 2026年で検証。過去の連系オッズは無いため単勝オッズから Harville 式で作った近似オッズで期待値を出す (回収率は実際の払戻)。見送り無しの買い方も同時に比較し、結果を `models/profit.json` に書く |
| 台帳 (`ledger.py`) | SQLite に予想を保存し、払戻で 1点100円換算の回収率を集計 |

`models/` (学習済みモデル・成績表・検証結果) が無い環境では、馬柱の簡易レーティング (`model.py`) に落ちて動く。

## 検証で分かったこと (2026年9月時点)

2021〜2026年の 17,955レース (2022年は約3分の2) を集め、2025年前半・後半・2026年をそれぞれ
「それ以前のデータだけで学習」して予想した学習外 5,741レースでの成績。

| 指標 | 統計のみ | 市場+統計補正 | 市場 (1番人気・単勝オッズ) |
|---|---|---|---|
| 本命の勝率 | 26% | 31.6% | 33.4% |
| 対数損失 (低いほど良い) | 2.136 | **1.960** | 1.925 |

- **統計のみ** (オッズを混ぜない) では、どの券種・どの期待値の下限でも回収率 55〜86% で 100% を超えなかった
- **市場+統計補正** (単勝オッズの確率のロジットを初期値にし、木は統計特徴量で市場からの補正分だけを学ぶ。
  3シード平均) が最良。2023年以降だけで学習していた版 (1.971) より、2021〜22年を足して 1.960 まで改善した
- 採用したのは **単勝・期待値1.3倍以上・新馬/未勝利戦を除く**: 2025年 797点 回収率 108% (+6,390円)、
  2026年 630点 回収率 106% (+4,090円)、的中率 7〜8% (1点100円)。1.2倍以上 (103% / 109%)・1.5倍以上 (142% / 110%)
  でも両年プラスで、下限に依らず優位が出ている
- 内訳: 芝は 2025年 99%・2026年 145%、ダートは 2025年 116%・2026年 79%。オッズ帯では 10〜20倍 105%・20〜40倍 146%・
  10倍未満 78%。**2026年のダートは弱い** (モデルと市場の差が最も大きい区分) ので、ダートは控えめに
- 期待値が下限を超える組が無いレースで「見送らず買う」なら 単勝 期待値上位1点 (2025年 95%・2026年 102%)
- 馬連・ワイド・馬単・三連単は過去の実オッズが無く近似オッズでの検証になり、年ごとに 0%〜200% とぶれるため **採用しない**
- 三連複は「確率の高い順」に買えば過去の払戻で正確に答え合わせできる。全レースでは回収率 80〜87% だが、
  本命の勝率 50% 以上 かつ 上位3頭の勝率合計 85% 以上の「カチカチに固い」レースに絞って上位2点なら
  2025年 98%・2026年 110%、的中率 41%。単勝1.5倍以下のような人気で区切ると配当が安すぎて 70〜90% にとどまる。
  利益の柱は単勝で、三連複は当てにいく補助としてカチカチのレースだけ出す (`backtest/trio_rule.py`、`models/trio.json`)
- 効かなかったもの: 統計のみのランキング学習、芝ダ別モデル、馬の通算成績 (収集期間の分だけでは逆効果)、
  条件別 (芝ダ・頭数・クラス・オッズ帯) の自動除外 (選定期間のぶれに合わせてしまい検証期間で裏目)
- 学習の乱数や行の並びだけで買い目の回収率は ±10 ポイント動く。特徴量の良し悪しは対数損失で判断すること

### 追加情報の検証 (2026年9月)

調教評価 (追い切り A〜D と短評、全 19,750レース)、父・母父の系統、騎手と調教師の直近60日の成績とコンビ・コース別成績、
コース別の枠と脚質の有利不利、馬場状態×脚質、天気を集めて検証した。

- 騎手や種牡馬の勝率表を「そのレースより前の結果だけで日付順に積み上げる」方式に直すと、勝率の当て方は
  対数損失 1.960 → 1.9205 と大きく改善し、初めて市場 (1.925) を上回った
- ただしそのモデルは市場に近い確率を出すため期待値の高い馬が減り、単勝の期待値買いは 2025年 213点 130% / 2026年 491点 101%、
  三連複カチカチは 95% / 90% と、今のモデル (単勝 108% / 106%、三連複 98% / 110%) を上回らなかった
- 追加した4グループ (調教評価・系統・騎手調教師・コース) は、足しても足さなくても差が誤差の範囲だった
- そこで予想と買い目は今のモデルのままにし、集めた情報は画面表示 (調教・系統・騎手60日・コースの特徴) に使う
  (`models/lines.json`・`form.json`・`display_stats.json`)
- JRA-VAN の調教タイムは毎週の最新分を取るのに有料会員と Windows での作業が要るため使っていない

## モデルを作り直す## モデルを作り直す

```bash
cd keiba
python backtest/collect.py --from 2021-01 --workers 2   # 数時間。中断しても続きから (弾かれるなら KEIBA_PREFER_CURL=1)
python backtest/train.py                                 # 時系列で検証しつつ学習し models/ を更新 (統計のみ・市場補正の両方)
python backtest/profit.py --shrink 1.0                   # 賭け方 (期待値の下限・見送り無し) を検証
python backtest/ablation.py                              # 特徴量グループの足し引き実験
python backtest/dirt_lab.py                              # ダート改善の実験 (芝ダ別モデル・縮小率の比較)
```

## 動かす

```bash
cd keiba
pip install -r requirements.txt
streamlit run app.py
```

| 環境変数 | 既定 | 用途 |
|---|---|---|
| `DATA_DIR` | `keiba/data` | 台帳 (SQLite) の保存先。Streamlit Cloud / Render 無料プランでは再デプロイで消えるので CSV で控えること |

Streamlit Community Cloud にデプロイする場合は Main file path に `keiba/app.py` を指定する。

## 注意

- 馬券の控除率は 20〜27.5% あり、どの買い方でも長期的な利益は保証されない。期待値 1.0 超の買い目だけが理論上のプラス
- 検証成績は過去データでの結果で、将来も同じとは限らない。台帳で答え合わせを続け、当たらない券種は買わないこと
- データは netkeiba の公開ページのみ。JRA公式サイトはクラウドからのアクセスを拒否するため使っていない
- 予想は参考情報であり、購入は自己責任で。20歳未満の馬券購入は法律で禁止されている
