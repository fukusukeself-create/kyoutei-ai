# 🏇 中央競馬 統計予想

JRA (中央競馬) の開催一覧からレースを選ぶと、**過去レースから学習した統計モデル**が
各馬の勝率を出し、単勝・馬連・ワイド・三連複の買い目を組む Streamlit アプリ。
AI (LLM) は使わない。競艇日和アプリと同じ操作感 (開催一覧 → 場・R → ⚡予想) で、
スマホ幅 (380〜450px) に最適化。予想は台帳に残して結果と答え合わせできる。

## 画面の流れ

1. **開催日** を選ぶ (既定は今日。開催が無い日は次の開催日を案内)
2. **🏁 開催一覧** の場カードをタップ → その場の次のレースをそのまま予想。
   **⏰ 発走順** タブなら全場のレースを発走時刻順に選べる
3. 別のレースは **開催場 / レース / スタイル** のピルで選び **⚡ 予想する**
4. 出るもの
   - 判定バナー: 本命・勝率・自信 (自信あり / 普通 / 混戦)
   - 買い目: 単勝 (期待値1.1倍以上のみ) / 馬連 / ワイド / 三連複。緑枠は期待値1.0超。
     スタイルは 堅実 (点数を絞る) / バランス / 穴狙い (馬連15倍以上・三連複50倍以上を期待値順)
   - 印・推定勝率・3着内率・単勝オッズ・期待値・根拠 (前走勝ち / 昇級戦 / 同距離帯◎ / 父がこの条件得意 …)
   - 出馬表・近5走・血統 (父・母父)
   - 発走前は「オッズ更新」で組み直し。確定後は結果と払戻
5. **📒 成績・答え合わせ** — 台帳の予想を払戻と突き合わせ、券種別の的中率・回収率・収支。CSV書き出し可
6. **📈 モデルの検証成績** — 学習に使っていない直近期間での成績 (市場との比較)

## 予想の仕組み (統計モデル)

| 段階 | 内容 |
|---|---|
| データ (`backtest/collect.py`) | netkeiba から 2023年以降の全レースについて、**出走時点の馬柱** (近5走・父・母父・脚質・間隔・馬体重) と **結果・払戻・確定オッズ** を収集し SQLite に保存 |
| 特徴量 (`features.py`) | 近5走の着順・着差・人気・クラス差・上り、**同じ芝ダ / 距離帯 / 競馬場 / 馬場状態での成績 (距離適性・コース適性)**、昇級か降級か、休み明け、斤量と平均との差、馬体重と増減、枠・馬番、年齢・性別、脚質と展開 (逃げ先行の頭数)、**父の芝ダ×距離帯別成績・母父の芝ダ別成績 (血統)**、騎手・厩舎の勝率と3着内率 (いずれも学習期間から平滑化して算出) |
| 学習 (`backtest/train.py`) | LightGBM の二値分類 (勝ち / 3着内) を学習し、レース内で正規化して勝率に。学習期間と検証期間を時系列で分け、検証期間で市場 (単勝オッズ) と対数損失・1番手的中率・回収率を比較 |
| 市場との混合 (`statmodel.py`) | 単勝オッズから控除率を除いた市場確率と幾何平均。混合比は検証期間で対数損失が最小になる値を採用 (オッズ未発売ならモデルのみ) |
| 買い目 (`strategy.py`) | 勝率から Harville 式 (2・3着は指数で緩和) で馬連・ワイド・三連複・3着内の確率を作り、確率の高い順に目標の的中率に届くまで買う。オッズがあれば期待値を併記 |
| 台帳 (`ledger.py`) | SQLite に予想を保存し、払戻で 1点100円換算の回収率を集計 |

`models/` (学習済みモデル・成績表・検証結果) が無い環境では、馬柱の簡易レーティング (`model.py`) に落ちて動く。

## モデルを作り直す

```bash
cd keiba
python backtest/collect.py --from 2023-01 --workers 3   # 数時間。中断しても続きから
python backtest/train.py --valid-from 20260301           # 学習・検証して models/ を更新
```

## 動かす

```bash
cd keiba
pip install -r requirements.txt
streamlit run app.py
```

| 環境変数 | 既定 | 用途 |
|---|---|---|
| `DATA_DIR` | `keiba/data` | 台帳 (SQLite) の保存先。Streamlit Cloud / Render 無料プランでは再デプロイで消えるので CSV で控えること |

Streamlit Community Cloud にデプロイする場合は Main file path に `keiba/app.py` を指定する。

## 注意

- 馬券の控除率は 20〜27.5% あり、どの買い方でも長期的な利益は保証されない。期待値 1.0 超の買い目だけが理論上のプラス
- 検証成績は過去データでの結果で、将来も同じとは限らない。台帳で答え合わせを続け、当たらない券種は買わないこと
- データは netkeiba の公開ページのみ。JRA公式サイトはクラウドからのアクセスを拒否するため使っていない
- 予想は参考情報であり、購入は自己責任で。20歳未満の馬券購入は法律で禁止されている
